LEX-CODE-TRAINER

Lex reveals code a single line at a time. The next line stays hidden until the learner explains the current line in technical detail, in their own words, well enough to prove they read it rather than skimmed it.

The repository How the gate works

First stretch: the gate

Read the revealed line, write or speak the explanation, earn the following line, repeat until the file ends. A learner who cannot explain a line stays with that line. That staying is not a punishment screen, it is the product.

python3 lex.py                  # list lessons
python3 lex.py --lesson loops   # study a lesson
python3 lex.py --file code.py   # line-by-line mode for your own code

There are three built-in lessons: functions, loops, and api. This project is complete and runnable, with no dependencies beyond the Python 3 standard library.

Second stretch: what a session holds

In a lesson, each line is graded against its key concepts: your explanation needs to mention at least half of them (stem matching, so accumulate covers accumul) to be counted as correct enough. Typing skip reveals the next line without credit. At the end, Lex prints your understanding score as a percentage of the graded lines. Blank lines are shown but not graded.

In --file mode your explanations are not graded: Lex shows each non-blank line of your file and waits for you to type an explanation or press Enter before revealing the next line. If both --file and --lesson are given, --file takes precedence.

Where a session is not a built-in lesson, its format is set by the person running Lex. The repository documents no account system and no leaderboard, and this page invents none.

Third stretch: the tutor's margin

Two marks live in this manual's margin. The green window is the lesson's patience: one line, lit, held open until it is understood. The red pencil is the tutor's insistence: explain the line in technical detail, in your own words, or the mask does not move.

Lex sides with both at once. It demands the mechanism, stated out loud, and it trusts that repeated explaining turns into judgement.

Run the tests with python3 -m unittest: 20 tests cover grade() on its own, scripted lesson runs, and file mode.
